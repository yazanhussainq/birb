تعلّم GitHub بخطوات عملية واضحة

الأدوات التي يحتاجها كل مطوّر لحفظ الكود، والعمل مع الفريق، ومراجعة التغييرات بثقة.

ابدأ من المهارات الأساسية

المهارات الأساسية

ست مهارات تغطي معظم ما ستستخدمه يوميًا. كل مهارة معها الأمر الذي تحتاجه مباشرة.

إنشاء المستودع

المستودع (Repository) هو المكان الذي يُحفظ فيه مشروعك وتاريخ تغييراته كاملًا.

git init
git remote add origin <url>

الحفظ (Commit)

كل commit لقطة محفوظة من الكود مع رسالة تشرح ما تغيّر ولماذا.

git add .
git commit -m "add login page"

الفروع (Branches)

اعمل على ميزة جديدة في فرع مستقل دون التأثير على الكود الرئيسي.

git checkout -b feature/payment
git checkout main

طلب الدمج (Pull Request)

اطلب من الفريق مراجعة تغييراتك قبل دمجها في الفرع الرئيسي.

git push -u origin feature/payment
# ثم افتح Pull Request من موقع GitHub

المزامنة مع الفريق

اسحب آخر التغييرات قبل أن تبدأ العمل حتى تتجنب التعارضات.

git pull origin main
git status

المشاكل والأتمتة

استخدم Issues لتتبّع المهام، وGitHub Actions لتشغيل الاختبارات تلقائيًا.

# .github/workflows/test.yml
on: [push, pull_request]

مسار التعلم

اتبع الترتيب التالي، ولا تنتقل لخطوة قبل أن تجرّب السابقة على مشروع حقيقي.

  1. ثبّت Git وأنشئ حسابًا على GitHubاضبط اسمك وبريدك باستخدام git config.
  2. أنشئ مستودعًا واحفظ أول commitابدأ بمشروع صغير: صفحة HTML أو سكربت بسيط.
  3. ارفع المشروع إلى GitHubاربط المستودع المحلي بالبعيد باستخدام push.
  4. تعلّم الفروع والدمجأنشئ فرعًا لميزة، ثم ادمجه في main.
  5. شارك في مشروع مع شخص آخرافتح Pull Request وراجع كود غيرك.
  6. أضف الأتمتةاكتب workflow بسيطًا يشغّل الاختبارات عند كل push.

أهم الأوامر

مرجع سريع للأوامر التي ستكررها كثيرًا.

الأمرماذا يفعل
git clone <url>ينسخ مستودعًا من GitHub إلى جهازك.
git statusيعرض الملفات المعدّلة وغير المحفوظة.
git add .يجهّز كل التغييرات للحفظ.
git commit -m "msg"يحفظ التغييرات مع رسالة وصفية.
git pushيرفع الحفظات إلى GitHub.
git pullيسحب آخر التغييرات من GitHub.
git log --onelineيعرض تاريخ الحفظات بشكل مختصر.
git stashيخفي التغييرات مؤقتًا للرجوع إليها لاحقًا.

نصائح عملية

عادات صغيرة تفرّق كثيرًا في العمل الجماعي.

  • اكتب رسائل commit قصيرة تبدأ بفعل: "add"، "fix"، "update".
  • احفظ التغييرات الصغيرة كثيرًا بدل حفظة ضخمة واحدة.
  • لا تعمل مباشرة على main؛ أنشئ فرعًا لكل مهمة.
  • أضف ملف .gitignore قبل أول commit.
  • اسحب التغييرات (pull) قبل أن تبدأ العمل يوميًا.
  • اكتب README يشرح كيف يُشغَّل المشروع.
